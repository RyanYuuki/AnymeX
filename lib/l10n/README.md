# AnymeX Localization (i18n)

AnymeX uses Flutter's official localization (`flutter_localizations` + `gen-l10n`). Strings live in ARB files managed through [Weblate](https://weblate.org). The selected language is persisted via Hive by `LocaleController`.

---

## Directory Structure

```
l10n.yaml                        # gen-l10n config (repo root)
lib/l10n/
├── app_en.arb                   # English — template / source strings
├── app_<code>.arb               # One file per language (app_fr.arb, app_pt_BR.arb, ...)
├── app_localizations*.dart      # Generated by `flutter gen-l10n` (gitignored)
├── l10n_extension.dart          # `context.l10n` accessor
├── locale_controller.dart       # Language state, Hive persistence, runtime switcher
└── README.md                    # This guide
```

The Dart code is regenerated on every `flutter pub get` and build (`generate: true` in `pubspec.yaml`). Run `flutter gen-l10n` after editing `app_en.arb`.

---

## Weblate Setup

Weblate settings live on the server, not in this repo. Create a component with:

| Setting | Value |
|---|---|
| File format | ARB file |
| File mask | `lib/l10n/app_*.arb` |
| Monolingual base language file | `lib/l10n/app_en.arb` |
| Source language | English |
| Version control system | GitHub pull requests |

Install the **Cleanup translation files** add-on so strings removed from `app_en.arb` disappear from every language.

Translate through Weblate rather than editing language files by hand; direct edits can conflict with Weblate's pending changes. `app_en.arb` is the exception: edit it in the repo.

## How to Use in UI

### 1. Add the string to `app_en.arb`
```json
"clearCache": "Clear Cache"
```
Keys are camelCase Dart identifiers. Missing translations fall back to English.

### 2. Use it
```dart
import 'package:anymex/l10n/l10n_extension.dart';

Text(context.l10n.clearCache)
```
Outside widgets (controllers, models, code after an `await`), use the root context: `Get.context!.l10n.clearCache`.
Never call `context.l10n` in `initState`/`dispose` or on a context that may be unmounted.

### 3. Placeholders
```json
"episodeCount": "{count} Episodes",
"@episodeCount": { "placeholders": { "count": { "type": "String" } } }
```
```dart
Text(context.l10n.episodeCount('12'))
```

### Rules
- Never localize dynamic content (titles, synopses, character names, scraper output).
- Don't localize strings used for logic (map keys, `==` checks); localize at display.
- `settings_registry.dart` keeps plain English strings as stable IDs. `settings.dart` displays them through `settingsLabel()` in `registry/settings_labels.dart`: add a case there when you add a registry string. `test/settings_labels_test.dart` fails if one is missing.

## How to Add a New Language

### Step 1: Create the translation file
Start the language in Weblate; it commits `lib/l10n/app_<code>.arb`. A language with a country code (e.g. `app_pt_BR.arb`) also needs the language-only file (`app_pt.arb`).

### Step 2: Register in `locale_controller.dart`
Add the language option to `supportedLanguages`:
```dart
    const LanguageOption(
      locale: Locale('ja', 'JP'),
      name: 'Japanese',
      nativeName: '日本語',
    ),
```

The language will automatically appear in **Settings > Content & Preferences > Language** and update the UI across mobile and desktop layouts in real-time.
